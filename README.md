# ⚖️ LawQuiz

국가공인 자격증 수험생을 위한 **법 조문 OX 암기 퀴즈** 서비스입니다.
현행 법령 조문을 바탕으로 OX 문제를 자동 생성하고, 틀린 문제는 오답노트에 모아
반복 학습할 수 있도록 도와줍니다.

## 🔗 바로 써보기

별도 설치 없이 `index.html`을 브라우저로 열기만 하면 바로 동작합니다.
(서버/DB 없이 정적 HTML + 브라우저 저장소만으로 구동됩니다.)

## ✨ 주요 기능

| 페이지 | 설명 |
| --- | --- |
| 소개 (`index.html`) | 서비스 소개 및 "문제 풀러 가기" CTA |
| 문제 풀기 (`quiz.html`) | 법령 선택 → OX 문제 출제 → 정답 제출 시 즉시 정오답 표시 + 원본 조문 해설 → 다음 문제 |
| 오답노트 (`wrong-notes.html`) | 틀린 문제를 학습 회차별로 자동 저장, '이해 완료' 체크로 목록에서 제거 |
| 자유게시판 (`board.html`) | 제목/내용 작성 + 목록, 제목 클릭 시 같은 페이지에서 내용이 펼쳐지는 방식(별도 상세 페이지 없음) |

## 🛠 기술 스택

- 순수 HTML / CSS / JavaScript (프레임워크·빌드 도구 없음)
- 데이터 저장은 브라우저의 `localStorage` / `sessionStorage` 사용
  - 오답노트: `lawquiz_wrong_notes`
  - 게시글: `lawquiz_board_posts`
  - 학습 회차 구분: `sessionStorage` (탭을 새로 열면 새 회차로 시작)
- 별도 서버·데이터베이스 없음 → 브라우저마다, 기기마다 독립적으로 데이터가 저장됩니다.

## 📁 폴더 구조

```
law-quiz/
├─ index.html          # 소개 페이지
├─ quiz.html           # 문제 출제 페이지
├─ wrong-notes.html     # 오답노트 페이지
├─ board.html          # 자유게시판 페이지
├─ css/
│  └─ style.css
├─ js/
│  ├─ data.js          # 법 조문 샘플 데이터 + 문제 생성 로직
│  ├─ storage.js       # 오답노트 저장 유틸
│  ├─ common.js        # 공통 네비게이션 스크립트
│  ├─ quiz.js
│  ├─ wrong-notes.js
│  └─ board.js
└─ PRD.md              # 기획 문서
```

## ⚠️ 알아두면 좋은 점

- **법령 데이터는 샘플입니다.** 국가법령정보센터(law.go.kr) Open API는 브라우저에서
  직접 호출하기 어려워(CORS 미허용 + 이메일 인증키 필요) 실시간 연동 대신 민법·형법
  일부 조문을 `js/data.js`에 정문/오답 버전으로 미리 담아 문제를 생성합니다. 실서비스
  전환 시에는 서버(프록시)를 두고 그쪽에서 API를 호출하는 구조가 필요합니다.
- **게시판/오답노트는 로컬 저장입니다.** 진짜 DB가 아니라 내 브라우저의
  `localStorage`에 저장되므로, 다른 사람과 공유되지 않고 캐시를 지우면 사라집니다.
